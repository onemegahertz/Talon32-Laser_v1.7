# Talon32-Laser_v1.7
Талон-32: Учет посетителей с RFID и веб-панелью
Проект "Талон-32 v.1.7"
Комплектующие
ESP32 Dev Module
RFID-считыватель RC522
Дисплей LCD 1602 (I2C)
Модуль RTC DS3231
Светодиоды (зелёный, красный, оранжевый)
Пьезоизлучатель
Лазерный диод
Фоторезистор/фотодиод
Резисторы, конденсаторы
Макетная плата и перемычки
Схема подключения
RC522: MOSI (23), MISO (19), SCK (18), SDA (21)
LCD 1602: SDA (21), SCL (22)
RTC DS3231: SDA (21), SCL (22)
Лазер: GPIO (4)
Фоторезистор: GPIO (36)
Светодиоды: GPIO (13, 12, 14)
Пьезоизлучатель: GPIO (27)
Основные функции
Учёт посетителей ресторана и столовой
RFID-идентификация гостей
Контроль времени посещений (завтрак 8:30-11:30, обед 13:30-15:30, ужин 18:00-20:00)
Система лазерного контроля прохода
Веб-интерфейс администратора
Отчёты по посещениям
Интеграция с Telegram
Отправка отчётов на email
Особенности реализации
Чётные/нечётные ID для разных заведений
Защита от повторного посещения в один период
Автоматическое переподключение к Wi-Fi
Резервная точка доступа при потере связи
Неблокирующая архитектура без delay()
Защита от переполнения millis()
Административная панель с авторизацией
Поддержка Arduino Core 3.x
Установка
Установить Arduino IDE 2.x
Установить ESP32 Core 3.x
Загрузить требуемые библиотеки
Настроить параметры Wi-Fi
Загрузить прошивку в устройство
